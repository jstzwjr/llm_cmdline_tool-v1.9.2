[v1.9.2]
- Important Bug Fixes:
  - Fixed a critical bug in ThreadPool::joinAll() where deadlock may occur in certain cases.
  - Fixed possible race condition in Allocator::mAllocatedBuffers by adding mutex locks.
  - Fixed incorrect memory movements in CacheEvictionAgent::evictCacheAbs().
  - Enabled cache eviction in MLLM build by limiting -fexceptions compile flag to image_transform.cpp only.
    - This fixes a segfault error when running cache eviction in MLLM build by making the linking consistent with -fno-exceptions.
- Feature Updates:
  - Cache Eviction:
    - Added GlobalSnapKV cache eviction algorithm. NOTE: Currently it only supports Left and Right cache shrink modes.
    - LocalSnapKV updates:
      - Added support for ingraph attention reduction to perform reduce Ops in NPU.
      - Added an option to disable SinkRoPE.
  - Neuron Adapter updates:
    - Added error checks for all Neuron Adapter API calls.
    - Added an API to reset global NeuronAdapterLib instance.
    - NeuronAdapterLib now defaults to search for NP9 USDK library file (libneuronusdk_adapter.9.mtk.so) instead of libneuronservice_adapter.mtk.so.
  - Added split-mask support for all existing masking modes.
  - KV Cache Save & Restore:
    - Added APIs to save and restore non-padded KV cache data on-the-fly: mtk_llm_get_nopad_caches_nbytes, mtk_llm_save_nopad_caches, mtk_llm_restore_caches.
    - Added a feature to auto detect and pad KV cache data during init or manual restore.
  - Model swapping flexibility:
    - Added support for swapping to models with smaller cache sizes.
    - Added support for swapping to models with different number of IOs via OrderedKinds and MutableIO utils.
  - Dump handler now writes to unique directories based on datetime.
  - Enabled prepare_huggingface_tokenizer.py to support list entries in huggingface tokenizer merges.
  - Added Gemma preformatter.
- Optimization:
  - Reduced inference overhead by adding --disable-invalidate-output option to backend runtime to skip unnecessary output invalidations during inference.
  - Cache eviction agents now reuses thread pool across inference steps to reduce thread creation/destruction overhead.
  - Added 'Left' and 'Adaptive' cache eviction shrink mode to allow flexible and more efficient cache eviction process.
    - Originally only supports right shrink mode.
    - Adaptive shrink mode is currently only supported for LocalSnapKV.
- Engineering:
  - Simplified LlmExecutor::assignBufferSizesToMax() by allowing IoBufferInflator to accept customized size calculations.

[v1.9.1]
- Added split mask support for autoregressive mode.
- Added support for separate LM Head shared weights.
- Added Qwen3 preformatter.
- Added INT8 mask support.

- Updated main.cpp to reuse shared weights across yaml configs when --preload-shared-weights is used.
- Optimization:
  - Skipped unnecessary input flushes during inference to improve latency by disabling backend runtime sync input while using uncached buffer.

  - Neuron USDK backend now searches for libneuronservice_adapter.mtk.so by default.
  - Reduced dependency on HW data alignment constant to support multiple platforms that use different alignments.
  - Rebuilt third-party shared libraries to be 16 KB-aligned.
  - Updated OpenCV third-party library to v4.11.0.
- Bug Fixes:
  - Fixed a use-after-free bug in dma buffer allocator release.
  - Fixed utils function misalignments between header and source files.
  - Fixed a config naming from 'numAttnOutpus' to 'numAttnOutputs'.

- Model init now uses multi-threading to speed up.
- Add Neuron runtime QoS, default to performance mode.
